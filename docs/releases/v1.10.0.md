## What changed

- Capture a coffee/equipment label with the system camera or select an image through the Android picker. Bounded English OCR runs on-device; conservative drafts keep unknown details unknown and require review before a record is saved.
- Improve model catalog metadata and SAF transfer validation for the listed local models. A user-selected SAF directory is required; this release does not claim Kafi or Gemma download/inference was device-tested.
- Persist catalog, recipe, journal and sensory records through split lifecycle-aware ViewModels; harden backup/restore synchronization and prevent unsupported or partial assets from appearing installed.
- Keep extraction yield tied to measured beverage mass and TDS, with assumptions and approximate labeling. Preserve the independent Brew menu chips and focused cards.
- Close the keyboard before saving a form so validation feedback remains visible on compact screens.

## Acceptance still pending

The OCR device suite used generated images; real coffee bag/equipment photos and a human correction journey were not tested. The SAF asset test could not start because the test profile had no persistable grant for its QA tree URI; no user SAF data was touched. Qwen native generation, Kafi/Gemma transfer and inference, manual TalkBack/font-scale review, macrobenchmarks, independent RAG answer-faithfulness evaluation and sensory field review remain unverified. See the [full requirement checklist](../VERIFICATION.md).
