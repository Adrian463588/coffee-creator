## Changes

- Adds direct vibration and alarm-audio requests to the existing manual brew timer, with a **Test alert** action.
- Adds cue dispatch coordination between the timer screen and foreground service.
- Retains manual pour and espresso timing and manual weight entry; no physical BLE scale or machine connection is supported.

Sound, vibration, and notification delivery depend on device hardware, notification permission, and system sound/Do Not Disturb settings. Bypassing those settings is not guaranteed. The app's earlier on-screen wording and original release note stated a stronger guarantee; those claims should not be relied upon.
