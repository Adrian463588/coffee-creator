## Highlights & Resilience Bugfixes (`fix-timer-scale-session-crash`)

### 1. Zero-Crash Resilience for Active Brew Timer, BLE Scale, and Recipe Timer
- **Root Cause Resolution**: Resolved an unhandled `IllegalArgumentException: Recipe name cannot be blank.` that previously caused a fatal force-close crash when clicking **Connect Scale**, **Tare (0.0g)**, or **Start Session** (in *Brew -> Timer*), or **Start timer** / **Reset timer** (in *Brew -> Recipe*) before manually naming and saving a recipe.
- **5-Tier Resilient Fallback Resolution (`resolveActiveRecipe`)**:
  1. *Explicit Target*: Uses and validates `targetRecipe` if passed explicitly.
  2. *Safe Draft Synthesis*: Synthesizes `"Draft $effectiveMethod"` (e.g. `"Draft Pour Over (V60)"`) when `draft.fields["name"]` is blank, preserving the barista's custom dose, water, ratio, and temperature inputs without crashing.
  3. *Saved Recipe Fallback*: Resolves the first valid saved recipe from the user's library if draft parameters are missing.
  4. *Curated Champion Fallback*: Resolves the first validated recipe from the 76-recipe `WorldChampionRecipeCatalog`.
  5. *Guaranteed Static Fallback*: Returns `defaultFallbackRecipe()` (15.0g dose, 250.0g water, 93°C, 2 pour steps bloom & main pour) ensuring zero uncaught exceptions can ever propagate to the UI thread.
- **Defensive Coroutine Hardening**:
  - Wrapped `connectMockScale()`, `startBrewSession()`, `toggleTimer()`, and `tareScale()` in exception-safe blocks with diagnostic logging and friendly UI notices.
  - Safe `tareScale()`: Automatically initializes a clean zeroed session (0.0g mass, 0.0g/s flow rate) if triggered when session is uninitialized.

### 2. Stream Replay & Hang Prevention in Simulated Scale Driver
- **`replay = 1` Invariant**: Configured `SimulatedBleScaleDriver._weightStream` with `replay = 1` so that newly subscribed collectors immediately receive the latest emitted weight sample rather than suspending indefinitely.
- **Test Suite Timeouts**: Added `@Test(timeout = 5000)` across all scale and asynchronous flow unit tests to prevent test runner hanging in CI/local runs.

### 3. Tactile Industrial Microinteractions on Recipe Timer
- **Tactile Upgrades**: Upgraded Recipe Timer buttons to `TactileButton` and `TactileOutlinedButton` featuring 0.97f press micro-depression with medium bouncy spring physics and tactile haptic clicks.
- **Anti-Slop Layout**: Enforced `maxLines = 1` and `softWrap = false` with horizontal single-row layout to eliminate circular bubble wrapping.
- **Test Tags**: Added explicit `recipe:toggle_timer` and `recipe:reset_timer` semantics for automated UI testability.
