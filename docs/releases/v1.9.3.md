## Highlights & Anti-Slop Tactile Enhancements

### 1. Encapsulated Bag Inventory Item (Library Screen)
- **Eliminated Multi-Line Button Wrapping**: Replaced the unconstrained bag inventory row with an encapsulated `Surface` container (`RoundedCornerShape(10.dp)`, 1px hairline border, `surfaceVariant` 35% alpha).
- **Tabular Monospace Metrics**: Rendered remaining/package mass using monospace tabular numbers (`fontFeatureSettings = "tnum"`).
- **Clean Two-Row Balance**: Placed status chip badge (`[ACTIVE]`, `[FROZEN]`, etc.) and frozen indicator on a clean secondary line below the mass readout, preventing badge text wrap (`ACTIV\nE`).
- **Concentric Tactile Buttons**: Integrated `TactileOutlinedButton` ("Freeze"/"Thaw") and `TactileButton` ("Brew -18g") with strict single-line constraints (`maxLines = 1`, `softWrap = false`) and `RoundedCornerShape(8.dp)`. This eliminates accidental circular bubble button distortion when row space is constrained.

### 2. Action Headers Modernization (Journal & Sensory)
- **Cafe Cup Logbook Header**: Title given `Modifier.weight(1f)` plus secondary subtitle (`Manual entry · Zero cloud maps`) and a compact `TactileButton` with `Icon(Icons.Default.Add)` + `"Add Cup"` (`maxLines = 1`), eliminating the 3-line wrapped circular grey blob.
- **Cupping Sessions Header**: Weighted title + subtitle (`SCA / CoE protocol evaluations`) + `TactileButton` with `Icon(Icons.Default.Add)` + `"New Session"`, retaining `testTag("sensory:btn_new_session")`.
- **Roast-Rest Kinetics Header**: Weighted title + subtitle (`S2-062 degassing curve & logs`) + `TactileButton` with `Icon(Icons.Default.Add)` + `"Log Obs"`.

### 3. Reusable Tactile Primitives
- **TactileButton**: Standardized spring micro-depression (`scale = 0.96f` on press, `DampingRatioMediumBouncy`), `RoundedCornerShape(8.dp)`, and customizable compact padding.
- **TactileOutlinedButton**: Added outlined tactile variant with `scale = 0.96f` and `RoundedCornerShape(8.dp)`.
