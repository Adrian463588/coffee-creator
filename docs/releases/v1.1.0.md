# Coffee Creator v1.1.0

Replace prototype-only behavior with real Android persistence, local inference and
user-owned file operations. This APK is debug-signed, versionCode2, API26+,
arm64-v8a/x86_64. Reference-device verification and remaining acceptance layers are
documented in [VERIFICATION](../VERIFICATION.md).

## Changes

- Real Room/FTS4 records, migrations, immutable recipe revisions and draft recovery.
- Validated decimal quantities, exact Kotlin science, density/food-grade/allergen/
  supplier constraints, nullable measurements and explicit provenance/assumptions.
- Separate persisted sensory observations/estimates, uncertainty and ordinal overlay.
- Pinned actual CPU llama.cpp GGUF stream/cancel/unload, ONNX embeddings and local OCR.
- Real TXT/text/scanned-PDF import, source preservation/deduplication, ObjectBox HNSW
  hybrid retrieval, inspectable citations and no-evidence abstention.
- Typed tools, user review of named quantities, confirmed AI recipe writes and persona settings.
- Real SAF tree selection, manifest/size/SHA verification, private staging,
  HTTP Range/identity checkpoints, pause/cancel/retry and bundle discovery.
- Complete versioned SAF records backup/restore; corrupt exports preserve good records.
- Nine responsive Material3 screens, lifecycle-aware state, bounded background work,
  Hilt/Proto DataStore, static/BDD/physical-device suites and CI.
- Fix nullable-bean backup rejection, model control-token injection and numerical
  attribution; add regressions instead of silently weakening quality gates.
