# Coffee Creator v1.2.0 — Release Notes

Tactile Material3 UI refinements, chip-separated Brew navigation, custom bean and apparatus inputs, and curated specialty coffee datasets. This APK is debug-signed, API 26+, arm64-v8a/x86_64.

## Key Changes

### 1. UI Refinements & Modernization
- **Tactile Home Module Grid**: Replaced wrapped tonal buttons with high-contrast, bordered module tiles with icons (`Icons.AutoMirrored.Filled.Chat`, `Icons.AutoMirrored.Filled.LibraryBooks`, `Icons.Default.Memory`, `Icons.Default.Psychology`, `Icons.Default.Settings`) for clear visual hierarchy.
- **Responsive Brew Section Chips**: Brew sections (Recipe, Measurements, Ingredients, Tools) use multi-line wrapping `FlowRow` chips with semantic state descriptions, tactile active borders, and zero off-screen clipping on compact displays.
- **Enhanced Recipe Builder**: Added custom coffee bean text input with one-tap application (`form:custom_bean` and `form:add_custom_bean`) and custom brew apparatus text field (`form:custom_method`).
