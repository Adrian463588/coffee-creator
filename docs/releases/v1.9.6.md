## Highlights & Anti-AI Slop Tactile Microinteractions (2026 Spec)

### 1. Tactile Micro-Depression & Haptic Confirmation
- **Normative Spring Scale**: Standardized interactive touch targets (`TactileButton`, `TactileOutlinedButton`, `TactileFilterChip`, `Select` dropdown selectors, and `BrewSectionTabs`) with spring micro-depression (`scale = 0.97f`, `Spring.DampingRatioMediumBouncy`, `Spring.StiffnessLow`).
- **Physical Haptic Feedback**: Integrated `LocalHapticFeedback.current.performHapticFeedback(HapticFeedbackType.TextHandleMove)` on all interactive clicks, chip toggles, wheel sector taps, and modal confirmation buttons, giving immediate tactile confirmation under bench conditions.
- **TactileCard Primitive**: Added `TactileCard` supporting animated content sizing (`animateContentSize`), hairline borders, and subtle physical scale compression (`scale = 0.98f`) on press for clickable cards.

### 2. Tabular Monospace Metrics (Jitter-Free Telemetry)
- **Tabular Figures (`tnum`)**: Enabled `fontFeatureSettings = "tnum"` on all real-time numerical displays:
  - Active brew chronometer elapsed digits (`%02d:%02d`)
  - Live scale mass (`%.1f g`)
  - Rolling flow rate (`%.2f g/s`)
- **Layout Tremble Elimination**: Proportional digit width variance is eradicated, ensuring telemetry readouts remain rock-solid without horizontal layout jitter during high-frequency BLE sensor updates.

### 3. Concentric Nested Geometry & 1px Hairline Borders
- **Concentric Geometry**: Aligned nested component borders to the mathematical formula $R_{\text{inner}} = \max(0, R_{\text{outer}} - P)$, eliminating awkward mismatched inner curves.
- **Hairline Borders**: Uniformly calibrated card and container borders to a crisp 1px solid stroke with `MaterialTheme.colorScheme.outlineVariant.copy(alpha = 0.40f)`.
- **Anti-Slop Single-Line Constraints**: Enforced `maxLines = 1, softWrap = false, overflow = TextOverflow.Ellipsis` on dropdown items, action buttons, and status badges, preventing asymmetric circular bubble distortion.

### 4. Accessibility & Touch Ergonomics
- **48dp Hit Targets**: Enforced `Modifier.heightIn(min = 48.dp)` across all buttons, filter chips, and selectors.
- **Fluid Micro-Transitions**: Smooth animated transitions across dropdown arrow rotation (`tween(150)`), section switching, and modal dialogs.
