# Coffee Creator v1.4.0 — Release Notes

**Epic S2-E03: Active Brew Timer, BLE and Live Feedback (Stories S2-027 through S2-038).**
This distribution APK is debug-signed, targets Android 8/API 26+, and supports arm64-v8a/x86_64 architectures. Zero cloud dependencies.

## Key Changes in v1.4.0

### 1. Monotonic Active Brew Chronometer (S2-027, S2-028, S2-029)
- **Monotonic Hardware Timebase**: Timers bind to `SystemClock.elapsedRealtime()`, ensuring backgrounding, screen rotation, or wall-clock synchronization jumps cannot distort active brew timings.
- **Large Accessible Timer**: High-contrast, scalable display with semantic `LiveRegionMode.Polite` TalkBack announcements.
- **Step-by-Step Guidance**: Active step countdown, cumulative water targets, real-time water remaining, and next-step preview banner.
- **Flow Control & Interruption Recovery**: Pause, resume, step-skip, step-restart, and crash recovery from persisted session snapshots.

### 2. Smart Scale BLE Abstraction & Scientific Real-Time Filters (S2-032, S2-033, S2-034, S2-035)
- **Universal Scale Hardware Abstraction**: `BleScaleDriver` and `BleScaleManager` interfaces supporting GATT devices and an offline `SimulatedBleScaleDriver` for offline test suites.
- **Rolling OLS Flow Rate Derivation**: High-precision rolling ordinary-least-squares regression calculating real-time water flow rate in grams per second ($g/s$).
- **Scale Artifact & Discontinuity Filter**: Rejects physical pour-over artifacts (carafe swirl, spoon stir, vessel removal), holding steady filtered mass and flagging discontinuities.
- **Threshold Automations**:
  - Weight-triggered auto-start on kettle contact ($>0.5\text{g}$).
  - Automatic espresso flow cutoff ($<0.20\text{g/s}$ for $\ge 1.5\text{s}$ after reaching yield).
  - One-tap scale tare command ($0.0\text{g}$).

### 3. Proximity Indicators, Curves & Sensory Cues (S2-030, S2-036, S2-037, S2-038)
- **Target-Weight Proximity Badges**: Color-coded proximity states:
  - *Normal Flow* ($>10\text{g}$ remaining)
  - *Approaching Target* ($2\text{–}10\text{g}$ remaining)
  - *Imminent Cutoff* ($<2\text{g}$ remaining)
  - *Target Matched* ($|\Delta w| \le 0.5\text{g}$)
  - *Target Overshoot* ($>1.0\text{g}$ excess)
- **Tactile Sensory Cues**: 3-2-1 countdown ticks, step transition chimes, and target-reached vibration pulses.
- **Screen Awake Management**: Dynamic `FLAG_KEEP_SCREEN_ON` management while brewing is active.
- **Curve Deviation Metric**: Real-time piecewise ideal ramp generation and actual curve Root Mean Square Error (RMSE) computation.
- **Android Ongoing Notification**: Standard foreground service notification contract displaying synchronized chronometer, live weight, flow, and play/pause action buttons.

### 4. Automatic Journal Logging (S2-031)
- Automatic creation and persistence of a complete `SensoryObservation` record in the local database upon session finish, capturing actual duration, water mass, recipe link, and bean association for subsequent manual refinement.
