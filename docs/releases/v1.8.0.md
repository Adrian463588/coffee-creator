## What's New in v1.8.0

### 1. SAF Persistent Model/Asset Manifest & Reinstall Rediscovery (S2-075)
- User-owned models and metadata `.coffee-asset.json` persist in user-selected Storage Access Framework (SAF) document trees.
- Directory discovery scanner automatically rediscovers pre-downloaded GGUF weights after OS app uninstalls and reinstalls, eliminating redundant multi-gigabyte transfers.
- SHA-256 binary validation rejects altered or corrupt model files before registering in local catalog.

### 2. User-Initiated Resumable Model & OCR Downloads (S2-076)
- Resumable transfers using HTTP 206 Partial Content, `Range: bytes={offset}-`, and `If-Range: {etag}` headers.
- Persistent checkpointing retains partial files and partial SHA-256 digests.
- Detects upstream server changes (new ETags) and safely resets stream offset to 0 to prevent file corruption.
- Evaluates available storage before dispatching network calls, preventing storage exhaustion.

### 3. Cryptographic Full Backup & Atomic Restore (S2-077)
- Comprehensive JSON archive exporting all user data: recipes, custom beans, brew journal entries, cupping sessions, palate taste vectors, and unit settings.
- Enforces SHA-256 payload digest verification; corrupt or tampered files abort atomically with zero database mutations.
- Smooth migration across app revisions without silent data loss.

### 4. Bilingual On-Device Language (EN/ID) & Localized Physics Units (S2-078)
- Instant on-device language toggle between **English (EN)** and **Bahasa Indonesia (ID)** without requiring internet or app restarts.
- Localized brewing physics units:
  - Temperature: Celsius (°C) and Fahrenheit (°F)
  - Mass: Grams (g) and Ounces (oz)
  - Volume: Milliliters (mL) and Fluid Ounces (fl oz)
  - Elevation: Meters (masl) and Feet (ft)
- Pure Kotlin `BigDecimal` math guarantees roundtrip identity:
  $$|T_C - \text{toCelsius}(\text{toFahrenheit}(T_C))| < 10^{-6}$$
- Strict liquid volume-to-mass conversion requires verified density ($\rho > 0$).
- Built-in offline FAQ & error recovery guides for BLE disconnects, OCR failure, high-altitude thermodynamics, and reinstall recovery.

### 5. Adaptive Compose Layouts & Material 3 Accessibility (S2-079)
- Dynamic layout adaptation:
  - **Compact (<600dp)**: Single-column vertical scroll with bottom navigation.
  - **Expanded (>=600dp)**: NavigationRail with dual-pane master-detail workflows.
- Full compliance with WCAG 2.1 AA / Material 3 accessibility:
  - Minimum touch targets $\ge 48\text{dp} \times 48\text{dp}$ with $\ge 8\text{dp}$ spacing.
  - Non-linear font scaling up to $2.0\times$ (200%) without text clipping or ellipsis.
  - TalkBack screen reader support with polite live regions for timer and scale updates.

### 6. Bounded Circular Diagnostic Buffer & Zero Telemetry SDKs (S2-080)
- On-device 500-event circular ring buffer for troubleshooting without third-party analytics SDKs.
- Automatic PII regex scrubbing: masks IPv4 addresses (`[REDACTED_IP]`), local storage paths (`[LOCAL_STORAGE]`), and secret tokens (`token=[REDACTED]`).
- Opt-in local export generates sanitized markdown summary shared via Android Sharesheet with zero outbound network transmissions.

### 7. Graceful Degradation State Machine & Subsystem Status (S2-081)
- Unified status badges transparently communicate subsystem state:
  - `FULL_SYSTEM`: All subsystems nominal.
  - `MANUAL_TIMER`: BLE scale offline; virtual high-precision timer active.
  - `MANUAL_OCR`: Camera/OCR offline; manual text fields active.
  - `RULE_BASED_AI`: Local LLM missing; deterministic physical rules active.
  - `OFFLINE_CORE`: 100% manual barista workstation.

### 8. Regression & Performance Soak Matrix (S2-082)
- Monotonic clock timebase delta ensures timer cumulative drift is $< 50\text{ms}$ over extended brews.
- State preservation via `SavedStateHandle` survives Android OS process death and recreation.
- Bounded memory limits prevent OutOfMemoryError crashes under severe memory pressure.
