## What's New in v1.9.1

### 1. Anti-Slop Single-Row Category Navigation
- Eliminated the 3-row wrapping staggered `FlowRow` chips that consumed ~150dp of vertical viewport height.
- Replaced with a sleek, single-row horizontally scrollable category bar featuring dedicated icons:
  - **Beans & Bags**: `Coffee` icon
  - **Grinders & Gear**: `Settings` icon
  - **Water Chemistry**: `WaterDrop` icon
  - **Ingredients**: `Science` icon
  - **Green & Roast QC**: `Spa` icon
  - **Import / Export**: `ImportExport` icon
- Guaranteed minimum 48dp touch targets meeting WCAG 2.2 accessibility standards.
- Reusable `TactileFilterChip` with spring micro-depression physics (`scale = 0.96f`).

### 2. Unified Precision Laboratory Brew Chronometer
- Replaced disconnected timer cards and scattered controls with an integrated, high-contrast digital instrument cluster.
- **Digital Telemetry Cluster**: Large monospace tabular numbers (`fontFamily = Monospace`, `tnum`) displaying elapsed time (`00:00`), live beverage mass in grams (`0.0 g`), and rolling flow rate (`0.00 g/s`).
- **Live Pulse Status Indicator**: Real-time breathing LED indicator (`LivePulseIndicator`) animating smoothly between `1.0f` and `1.6f` scale with fade during active brewing.
- **Integrated BLE Scale Status & Quick Toolbar**: Displays connected scale device name or connection state, with instant `Connect Scale` and `Tare (0.0g)` actions.
- **Ergonomic Primary CTA Button**: Full-width 54dp primary button (`Start Session` / `Pause Session` / `Resume Session`) with tactile spring response (`scale = 0.97f`).
- **Segmented Secondary Actions**: Aligned secondary actions row (`Skip`, `Restart`, `Reset`, `Finish & Log`) with optimized content padding to guarantee crisp, non-truncated typography.

### 3. Formulation Screen Section Navigation
- Refactored `BrewSectionTabs` to a smooth, single-row horizontal scroll bar across all 7 brew workflow phases: `Recipe`, `Steps`, `Timer`, `Measurements`, `Ingredients`, `Tools`, and `Expert`.

### 4. Zero Regressions & 100% Test Integrity
- All automated Compose test tags (`timer:display`, `timer:step_card`, `timer:proximity_badge`, `timer:scale_card`, `timer:connect_scale`, `timer:tare_scale`, `timer:toggle`, `timer:finish_and_log`, etc.) preserved 100% without modification.
- All 202 domain and presentation unit tests pass cleanly.
- Verified on physical hardware: `Samsung SM-G988B` (Android 13 / API 33).
