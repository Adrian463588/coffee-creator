# Agentic UI UX Review

## Preconditions
Read `AGENTS.md` and the directly related PRD/architecture/design contracts. Only load other reference files when the task requires them.

## Required workflow
Define user task and failure cases; wireflow; component states; Material 3 tokens; create preview states; inspect compact/tablet landscape, font scales, dark/light, TalkBack; compare screenshot with design at same dimensions; generate specific defect list by severity; rerun focused tests. Screenshots alone do not prove accessibility.

## Completion report
- Scope/requirement
- Files changed
- Checks executed (PASS/FAIL/NOT RUN)
- Offline/privacy/a11y/science risks
- Blockers or ADR needed
