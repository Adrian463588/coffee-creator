# Coffee Creator — Agentic Android Development Starter Pack

This package contains specification and coding-agent governance documents, **not a compiled Android app**.

1. Copy these documents and `.agents/skills/` into the project root.
2. Open `PRD.md`, `AGENTS.md`, `DESIGN.md`, `ARCHITECTURE.md`, `TASKS.md` in your coding agent/Android Studio.
3. Start with Phase 0 and FR-03 science engine contract; do not begin with full autonomous agent fleet.
4. Use `AGENTIC_WORKFLOW.md` for delegation, and `MCP_TOOLING.md` for external development tools.
5. Customize minSdk, model choice, licenses, device test matrix via ADR before committing production dependencies.
6. Current docs reflect the source architecture supplied and public references checked in October 2026; package versions still require compatibility validation in the real project.

**Important distinction:** You can use online coding tools/MCP on your developer workstation; the shipped Coffee Creator Android app remains local/offline after explicit asset installation.
